# PW Controller v1.0.14 — perbaikan "Shizuku tidak berfungsi"

Tanggal: 24 Oktober 2026

## Ringkasan

v1.0.13 **tidak bisa dikompilasi** (listener izin Shizuku salah signature) dan belum pernah
diuji di perangkat. v1.0.14 memperbaiki kompilasi, membuat jalur injeksi *teramati* (bisa
dilihat hasilnya dari UI), dan mengganti asumsi koordinat hard-code dengan **kalibrasi target
per tombol** plus drag joystick yang benar.

---

## Akar masalah yang ditemukan

| # | Akar masalah | Bukti | Perbaikan |
|---|--------------|-------|-----------|
| 1 | **Source v1.0.13 tidak bisa dikompilasi.** `OnRequestPermissionResultListener` Shizuku 13.1.5 bertanda `(requestCode: Int, grantResult: Int)`, sedangkan kode memperlakukannya sebagai `(granted: Boolean, requestCode: Int)`. | `OverlayService.kt:203` → `Type mismatch: inferred type is Int but Boolean was expected` dari `compileDebugKotlin`. | Listener dibetulkan: cek `requestCode == REQUEST_CODE && grantResult == PERMISSION_GRANTED`. |
| 2 | **Deteksi izin Shizuku salah** → backend input tidak pernah berganti ke Shizuku setelah izin diberikan, diam-diam jatuh ke Accessibility (atau tidak ada backend sama sekali). | Callback lama memakai parameter pertama sebagai Boolean. | Sama seperti #1 + `refreshBackend()` dipanggil ulang pada `binder received / binder dead / permission granted`. |
| 3 | **Koordinat tombol native di-hard-code dari satu screenshot perangkat lain.** `0.11 / 0.205 / 0.797 / 0.889 × 0.87` — tebakan, bukan hasil pengukuran di perangkat ini. | `PROJECT-NOTES.md` v1.0.10: "Koordinat bawaan ... hanya diestimasi dari satu screenshot landscape dan dapat berbeda pada perangkat lain". | **Kalibrasi target per tombol** (Mode Edit → tahan tombol > 0,6 dtk → ketuk tombol asli di game) + preset yang bisa dikoreksi. |
| 4 | **Kiri/kanan disimulasikan dengan tap**, padahal Pixel Worlds memakai **virtual joystick** Unity yang hanya bereaksi pada *drag*. | Kode lama: `dpad_left` dan `dpad_right` pada dua X berbeda, `ActionType.HOLD` tanpa offset. | `startDragHold()` baru: jaruh turun di joystick lalu digeser ±5,5 % lebar layar, dengan ramp 90 ms supaya game melihat gerakan jari sungguhan. |
| 5 | **Injeksi tidak bisa diamati.** `injectInputEvent` dipanggil dengan mode ASYNC, hasilnya tidak pernah dicek, sehingga "tidak berfungsi" tidak bisa dibedakan dari "salah koordinat". | `ShizukuInjector.inject()` mengembalikan nilai yang diabaikan; error hanya di-`Log`. | Mode `WAIT_FOR_FINISH` untuk tes, counter `injectOk/injectFail`, `lastInjectDetail`, dan **menu "Tes Injeksi (Shizuku)"** yang menampilkan jawabannya. |
| 6 | **Tidak ada jejak yang bisa dibaca tanpa logcat.** | – | `DiagnosticsLogger` menulis `pwcontroller-diag.txt` ke `/sdcard/Android/data/com.pwcontroller/files/` (dan Download bila diizinkan). |
| 7 | **Perubahan arah gerakan bolong (gap).** `startHold()` melepas **semua** hold sebelum memulai yang baru → karakter berhenti bergerak saat ganti arah. | `ShizukuDispatcher.startHold()` → `releaseHolds()`. | Jari baru ditekan **sebelum** jari lama dilepas (*no-gap*), hanya tombol yang sama yang di-restart. |
| 8 | **UP nyasar (`stray UP`) ke game.** Runnable `pressFollow` yang tertunda tetap berjalan setelah slot dilepas → UP liar pada slot yang sudah dipakai. | `stopAllHolds()` membebaskan slot sebelum membatalkan runnable tertunda. | Runnable tertunda dibatalkan **lebih dulu**, baru slot dibebaskan. |
| 9 | **Race press-follow**: tap kedua hilang (DOWN datang saat UP tertunda). | Diperbaiki di v1.0.12 tapi masih menyisakan `return@post` di dalam `let`. | Preempt berjalan penuh; slot lama dilepas, DOWN baru tetap dikirim. |
| 10 | **Rotasi layar** mematikan service (overlay重建) dan membuat thread injeksi yatim. | Service tanpa `configChanges`. | `configChanges` + rebuild window overlay pada `onConfigurationChanged`, thread dilepas via `release()`. |
| 11 | **Error inisialisasi tidak informatif** (`lastError` hanya nama exception). | – | Pesan Mandarin/Indonesia yang menyebut tahap gagal (binder / asInterface / metode / SecurityException). |

## Cara memakai kalibrasi (penting)

1. Buka **PW Controller** → aktifkan **Mode Edit** (tombol alat).
2. **Tahan** tombol virtual yang mau dipindahkan (mis. tombol Lompat) selama lebih dari 0,6 detik.
3. Layar penuh akan menangkap sentuhan berikutnya → **ketuk tombol asli** (Lompat) yang ada di Pixel Worlds.
4. Posisi itu disimpan sebagai target tombol tersebut. Ulangi untuk Kiri, Kanan, dan Pukul.
5. Keluar Mode Edit, lalu coba lagi.

Preset (tanpa kalibrasi) memakai joystick di kiri bawah dan tombol aksi di kanan bawah.
