# PW Controller v1.0.9 — preset bersih tanpa wizard

Tanggal: 24 Oktober 2026

## Perubahan utama

- Wizard kalibrasi dihapus berdasarkan pilihan pengguna.
- Tombol **Kalibrasi** di halaman utama diganti **Reset Preset** dengan dialog konfirmasi.
- Satu mapping Pixel Worlds digunakan untuk semua profil; mapping hasil wizard lama dinormalkan saat profil dimuat.
- D-pad Atas dihapus karena duplikat Lompat. D-pad Bawah, Square, L1/L2/R1/R2 dihapus karena tidak memiliki aksi yang sesuai.
- Susunan overlay: Kiri/Kanan + analog, Lompat/Pukul, Slot 1–3, touchpad/kursor, dan tombol PW.
- Mode Edit memungkinkan grup window diseret dan menyimpan offsetnya. Reset Preset menghapus offset kustom dan memulihkan susunan default.

## Target preset aktif

| Kontrol | ID mapping | Aksi |
|---|---|---|
| Kiri | `dpad_left` | Hold target arah kiri native |
| Kanan | `dpad_right` | Hold target arah kanan native |
| Lompat | `cross` | Tap target lompat native |
| Pukul | `circle` | Tap target pukul native |
| Slot 1 | `select` | Tap hotbar slot 1 |
| Slot 2 | `triangle` | Tap hotbar slot 2 |
| Slot 3 | `start` | Tap hotbar slot 3 |

Analog memakai ulang `dpad_left`/`dpad_right`. Touchpad memakai posisi kursor dinamis.
